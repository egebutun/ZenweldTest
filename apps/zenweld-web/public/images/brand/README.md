# Marka görselleri

| Dosya | Nerede kullanılır |
|---|---|
| `zenweld-logo.svg` | Açık zeminler — üst menü, footer, yönetim paneli (kırmızı) |
| `zenweld-logo-light.svg` | Koyu zeminler — karşılama pop-up'ı (beyaz) |

## Logoyu değiştirmek

Aynı isimle üzerine yazın. PNG de kullanılabilir (`zenweld-logo.png`);
kod önce `.svg`, bulamazsa `.png` dener. Hiçbiri yoksa gömülü yedek logo
gösterilir, site kırılmaz.

Logo yatay olmalı ve etrafında fazladan boşluk bulunmamalıdır; site
yüksekliğe göre ölçekler (28–32 px).
